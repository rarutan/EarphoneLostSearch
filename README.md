# EarphoneLostSearch

## 1. 概要

USUMで乱数調整を行う際の、乱数消費管理をサポートするツールです。

3DSRNGToolと併用することを想定しています。このツールへ入力する際に、NPC数やTarget Frameへ独自の補正値を加える必要はありません。3DSRNGToolで確認した値をそのまま入力してください。

## 2. 注意事項

AIが作成したため、コードの書き方やロジックにおかしな部分が含まれている可能性があります。

既知の情報のみをもとに作成しているため、実機の動作と異なる場合があります。

## 3. ダウンロード

最新版は[GitHub Releases](../../releases)からダウンロードしてください。

## 4. 使い方

ここでは本ツールの操作方法のみ説明します。乱数調整全体の詳しい手順については、有識者の解説を参照してください。

`EarphoneLostSearch.exe`をダウンロードして起動し、使用するタブを選んで必要な条件を入力します。

### 4.1 孵化

#### 4.1.1 瞬き観測

孵化後の画面で、主人公の瞬きを観測します。

初期SEEDとNPC数を入力し、「瞬き確認スタート（Space）」を押すと観測状態へ移行します。実機画面で瞬きしたタイミングに合わせて、「瞬きを入力（Shift）」を押してください。キーボードではShiftキー、画面上のボタンではクリックで入力できます。

観測結果が確定すると音が鳴り、ツールのタイマーが動き始めます。左上パネルのずれ補正を使い、実機の瞬きとツールのタイマーが合うよう調整してください。

#### 4.1.2 補正項目

チェックボックスがある項目は、チェックを入れることで計算に反映されます。

- **Target Frame**：実際にエンカウントしたい目標Frameを入力します。
- **オフセット**：オフセットを考慮します。通常待機と最速閉じでは計算方法が異なります。
- **ロトムのお喋り**：ロトムのお喋りを考慮します。仲良し度が最大の場合の確率は79%です。
- **NPC初期読み込み**：フィールド開始時のNPC消費を考慮します。対象によって異なるため、基本的には1を入力してください。

現在は、現在位置→ロトム補正→NPCフィールド補正の順番で処理しています。ロトム補正の前にもし補正が必要な場合は、設定から入力してください。これは現在のアルゴリズムが間違っている場合の消極的な対応策です。

#### 4.1.3 実際のエンカウントまで

**通常待機**

右上パネルが○になったタイミングで、実機のBボタンと同時に「本番へ移行（Enter）」を押してください。タイマー終了と同時に実機でAボタンを押してエンカウントします。

**最速閉じ**

右上パネルが○になったタイミングで実機のBボタンを押し、最速閉じを行います。最速閉じ中にツールを操作する必要はありません。

#### 4.1.4 オフセットなどの補正

最速閉じの場合は、「ずれ検証に進む（Enter）」を押して補正確認へ進みます。この操作の前にリセットを押さないでください。

実際にエンカウントできたFrameと、ロトムがお喋りしたかどうかを入力して「ずれ補正」を押すと、オフセットとロトムのお喋り確率が計算されます。計算結果を反映したい項目だけ、それぞれのSetボタンを押してください。

### 4.2 フィールド

フィールド上にいる主人公やNPCの瞬きを確認します。

#### 4.2.1 設定

初期SEED、NPC数、検索範囲、NPC番号を設定します。

- **複数NPC**：指定した範囲内のNPC数を総当たりします。NPCが調整中に変動するケースには対応していません。
- **範囲**：左側の入力欄の開始位置を起点に検索します。3DSRNGToolに表示されるStartingFrameを正確に入力してください。ゲーム開始時や、QRコードリーダーを閉じる時点のFrameが該当します。
- **NPC番号**：主人公は`0`を入力します。内部で使用されるNPC番号のうち、観測対象にする番号を入力してください。分からない場合は`0`で試してください。

NPC番号の判定が`×`の場合は、入力したNPC番号が間違っています。`○`の場合でも正しいとは限らないため、あくまで目安として扱ってください。

#### 4.2.2 瞬き観測

「瞬き確認スタート（Space）」を押すと観測状態へ移行します。実機画面で瞬きしたタイミングに合わせて「瞬きを入力（Shift）」を押してください。

音が鳴り、ツールのタイマーが動き始めたら観測完了です。左上パネルのずれ補正を使い、実機画面の瞬きとツールのタイマーを一致させてください。

#### 4.2.3 エンカウントまで

3DSRNGToolで検索したTargetFrameを入力すると、Targetまでのタイマーが自動的に開始します。タイマー左側の↕ボタンで、瞬きタイマーとTargetタイマーを切り替えられます。タイマー終了と同時にエンカウントしてください。

#### 4.2.4 NPC番号補正

候補が確定したら「ずれ検証に進む（Enter）」を押してください。タイマーが停止し、ずれ検証用の入力が可能になります。実際に出現した個体のFrameを入力してから「idxを判定」を押すと、内部のNPC番号を判定できる場合があります。

⚠️ NPC番号補正の動作は保証されていません。この設定を反映した場合に、正常なTimelineを生成できるかは未検証です。

### 4.3 Timeleap機能

Timeleapを使って、フィールド上の別の乱数Timelineへ移動する手順です。

#### 4.3.1 検索前の準備

ゲーム内でTimeleapを行いたい位置まで進めます。その位置で通常のフィールド乱数と同じように瞬きを観測し、候補が確定したらタイマーを動かしておきます。

メイン画面のTimeleapにチェックを入れると、Timeleap前の瞬き数がFrame1までの数に切り替わります。検索ボタンを押すとTimeleap検索ウィンドウが開きます。

#### 4.3.2 Frame1検索

`Frame1検索`タブで検索条件を入力します。ウィンドウ上部の初期SEED、StartingFrame、NPC数、Frame1は検索元Timelineの情報です。必要に応じて編集し、`Reset`で現在メイン画面が使っている値へ戻せます。

- **カテゴリー**：3DSRNGToolのカテゴリー分類に対応します。
- **ポケモン**：対象のポケモンを選びます。選択に応じてTimeleap方式やConsider Delayが自動設定される場合は、通常そのままで構いません。
- **Timeleap方式**：どの操作でTimelineを移動するかを指定します。ポケモンを選ぶと方式が自動選択される場合は、その設定を使ってください。
- **Consider Delay**：3DSRNGToolで生成開始Frameを調べる際に考慮しなかったDelayを、この候補計算で考慮する設定です。自動設定された値を基本にしてください。
- **雨天時の注意**：カイロスは雨天時の乱数消費を考慮していません。今後需要がありそうなら実装します。
- **生成開始Frame**：欲しい個体が実際に生成されるFrameを入力します。3DSRNGToolではConsider Delayをオフにして検索したFrameを入力してください。
- **範囲指定**：候補一覧を作る範囲を指定します。`時間①秒数`または`Frame1`を選び、それぞれの開始・終了値を入力します。
- **猶予①**：同じ生成開始Frameに到達できるFrame1候補が連続する範囲の下限です。
- **猶予②**：同じ生成開始Frameに到達できるTargetFrame候補が連続する範囲の下限です。猶予は2F単位で扱います。

配達員方式を使う場合は`配達員`タブで条件を入力できます。[WC7およびWC7FULLファイル](https://github.com/projectpokemon/EventsGallery/tree/master/Released/Gen%207/3DS/Wondercards)を読み込めます。ライセンス上参照できない処理があるため、一部は推測に基づいて実装しています。そのため、3DSRNGToolと挙動が異なる場合があります。

`検索`を押すと、指定した生成開始Frameへ到達できるFrame1候補が一覧表示されます。候補を右クリックして`Frame1とTargetFrameをセット`を選ぶと、両方の値がメイン画面へ反映されます。

#### 4.3.3 Ready後のTimeleap

メイン画面で`Ready (Enter)`を押すと、選択中のFrame1候補を使う準備が行われます。準備中はTimeleap設定がロックされます。タイマー表示をFrame1までのカウントダウンにし、実機のTimeleap操作をFrame1に合わせて行ってください。

Timeleap後、実機の瞬きとツールの予測が合っていれば、そのTimelineのままTargetFrameまで待機し、タイマー終了に合わせてエンカウントします。実機の瞬きが合わない場合は、次の「瞬き状態を再確認」で実際に移動したTimelineを特定できます。

「そのままエンカウント」を有効にしておくと、Frame1通過後にTargetタイマーへ切り替わります。Frame1を通過したらすぐにエンカウントしたい場合に便利です。

#### 4.3.4 瞬き状態を再確認

Frame1通過後、実機の瞬きとツールの予測が合わない場合は、別のTimelineへ移動している可能性があります。`瞬き状態を再確認`を押すと、タイマーと表を止めて照合に入ります。このとき表示される入力欄は次の意味です。

- **再検索範囲（Frame1）±N**：Frame1候補を再特定するときに調べる範囲です。
- **予測現在地±N F**：予測された現在位置の前後どこまで候補Timelineを照合するかを指定します。再確認中は、通常の瞬き間隔許容差の代わりにこの範囲が使われます。

実機で瞬きしたタイミングに合わせて`Shift`を入力してください。照合できると実際に移動したTimelineが確定し、タイマーが再開します。

#### 4.3.5 TargetFrame検索とずれ確認

Timeleap後に別のTimelineへ移動していても、指定した生成開始Frameへ到達できるかは`TargetFrame検索`タブで調べられます。検索元のFrame1などを入力し、`検索`を押してください。検索結果には候補となるTargetFrameが表示され、指定した生成開始Frameに到達できる行は青くハイライトされます。

Timeleap自体は成功したものの、エンカウント結果が狙いと違った場合は、同じタブの`ズレ検索`を使います。

1. `生成開始Frame`に本来狙っていたFrameを入力します。
2. `ズレ検索`にチェックを入れ、実際に出た個体の生成開始Frameを入力します。これも3DSRNGToolでConsider Delayをオフにして調べたFrameを使ってください。
3. `F ±`には実測Frameの前後に表示する範囲を入力します。通常は初期値のままで構いません。`猶予`は候補を絞りたい場合に使い、通常は0で構いません。
4. `検索`を押すと、実測した生成開始Frameを中心にTargetFrameのTimeline上の連番が表示されます。

狙った生成開始Frameへ到達できるTargetFrameの行は青くハイライトされます。ズレ検索で入力した実測Frameと一致する候補は黒枠で囲まれます。一致する候補がない場合は、そのFrameに最も近い目安位置に表全体を横切る黒線が表示されます。黒線だけで黒枠の候補がない場合、入力した実測Frameへ到達できるTargetFrameはありません。

### 4.4 タイマー

通常の待機用タイマーです。オフセットを上から順番に実行し、最後に実際の待機時間を実行します。

## 5. 検索範囲について

SFMTの絶対位置は最大5,000万Frameまで扱えます。ただし、各タブで指定する検索範囲やTargetまでの距離には別途上限があり、通常の検索範囲は最大10万Frameです。
